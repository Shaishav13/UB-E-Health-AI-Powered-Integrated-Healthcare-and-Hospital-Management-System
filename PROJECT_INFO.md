## 🏥 Project Description
A comprehensive healthcare management system built with Node.js, MongoDB, and React. Features patient management, doctor portals, appointment scheduling, medical reports, and prescription management.

## 🚀 Technology Stack
- **Backend**: Node.js, Express.js, MongoDB, Mongoose
- **Frontend**: React 18, React Router, Axios
- **Authentication**: JWT, bcrypt
- **Database**: MongoDB with 16 seeded doctors across 8 specialties
