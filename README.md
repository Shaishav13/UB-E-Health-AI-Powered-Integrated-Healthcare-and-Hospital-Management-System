## Project Description
A comprehensive web-based Healthcare Management System that leverages AI to streamline hospital operations and improve patient care. The system provides separate interfaces for patients, doctors, lab personnel, and administrators to manage appointments, medical records, prescriptions, lab reports, and hospital resources efficiently.

### Key Features
- AI-powered health chatbot and report interpretation
- Patient, Doctor, Lab Personnel, and Admin portals
- Real-time appointment scheduling and management
- Digital prescriptions and lab reports
- Ambulance management
- Real-time chat system
- Email notifications

## Tech Stack
- **Frontend**: React.js, Redux, Material-UI, Ant Design
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **AI**: Google Gemini AI
- **Real-time**: Socket.IO
- **Authentication**: JWT, bcrypt
